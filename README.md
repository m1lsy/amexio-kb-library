# Amexio x KB: Library Discovery 2035

Industry project for Amexio, part of the ICT programme at Fontys University of Applied Sciences.

## Challenge
Rethink how people discover, explore and access everything a public library offers in 2035: books, events, workshops, creative spaces, digital resources and communities, without relying on a traditional search bar.

## Research question
> How might public libraries encourage serendipity and unexpected discovery in 2035, helping people find things they didn't know they were looking for without relying on a traditional search bar?

## Constraints
- The final solution must still be a website.
- Design principles: curiosity, serendipity, visual exploration, surprise, inclusivity, user control, privacy, public value.

## Prototypes
| Version | Name | Idea | Status |
|---|---|---|---|
| v0.1 | KB Drift | Mood sliders reorder a visual grid of books and events; a "surprise" dial injects detours | Done, awaiting feedback |

Each prototype lives in `prototypes/<version>-<name>/` and is never overwritten. Open `index.html` in a browser.

## Repo structure
- `prototypes/`: one folder per version
- `research/`: references, feedback notes, user tests
- `screenshots/`: one image per version
- `PROCESS_LOG.md`: running diary of goals, prompts, decisions and feedback

## Note on content
All books and events in the prototypes are sample data for concept purposes. Any "AI" behaviour is a frontend simulation.
